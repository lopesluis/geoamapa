# GeoAmapá

Plugin QGIS para consulta territorial do estado do Amapá.

## Função
Permite selecionar uma área pela extensão do mapa e consultar automaticamente diversas bases territoriais, gerando uma camada temporária com as feições encontradas.

Bases suportadas:
- CAR
- SIGEF
- INCRA
- Unidades de Conservação
- Terras Indígenas
- Assentamentos
- Direito Minerário

## Como usar
1. Abra o plugin GeoAmapá
2. Clique em "Capturar"
3. Escolha a base
4. Clique em "Consultar"

## Requisitos
QGIS 3.34 ou superior
